Detailed Description

Defines the Token structure and operations for handling lexical elements in text.

Provides types and functions for creating, printing, and working with tokens such as words, punctuation, and whitespace in the context of a text editor or tokenizer.

Token createToken ( const char * text,
Type type )

Creates a new token.

This function initializes a Token with the provided text and type, and returns it.

Parameters
textThe text content of the token.
typeThe type of the token (e.g., WORD, PUNCTUATION, WHITESPACE).
Returns
A newly created Token.
Note
The text provided is copied directly into the Token, and there is no need to handle memory allocation for the Token itself.
