Detailed Description

Defines the Paragraph structure and operations for handling text paragraphs.

This header declares the Paragraph structure and associated utility functions used for managing and processing paragraph content in the text editor project. It includes creation, tokenization, formatting (left/center alignment), statistics (character count, word count), and memory management functionalities.

Prints the paragraph with left alignment, wrapping lines at a maximum width.

This function formats and prints the paragraph so that each line has at most maxWidth characters. Words are wrapped to the next line at whitespace boundaries. The whitespace used for wrapping is not printed at the beginning of a new line.

Parameters
pPointer to the Paragraph structure to be printed.
maxWidthMaximum number of characters allowed per line (should be between 10 and 50).
