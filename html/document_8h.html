◆ documentCreate()

Document * documentCreate ( const char * name)

Allocates and initializes a new Document.

This function creates a new Document structure, sets its name, assigns the provided list of paragraphs, and initializes the load date.

Parameters
nameThe name of the document (typically the filename).
paragraphsThe list of paragraphs that make up the document content.
Returns
A pointer to the newly created Document, or NULL on failure.

Deallocates all memory used by a Document.

Frees the memory of the document, including all paragraphs in the list and the list structure itself.

Parameters
