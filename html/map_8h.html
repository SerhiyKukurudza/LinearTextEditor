◆ mapKeys()

MapKey * mapKeys ( PtMap map)

Retrieves the set of keys of a map.

This function returns a dynamically allocated array with length equal to the size of the map, containing the keys of the map in no particular order.

The caller is responsible for deallocating (freeing) the array.

Parameters
map[in] pointer to the map
Returns
array containing the keys
NULL if 'map' is empty or NULL
